## About This Lab

This lab uses JavaScript functions, event listeners, conditions, loops, and DOM manipulation to make web pages interactive.

- **Question 1 – Interactive Text Changer:** Changes “Welcome to my website!” to “Hello there!” when a button is clicked.
- **Question 2 – Smart Number Validator:** Checks whether an entered number is lower than, equal to, or higher than 10, and handles invalid input.
- **Question 3 – Dynamic Number Generator:** Generates a numbered list from 1 to 5 when the button is clicked.

## How to Run

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension if needed.
3. Right-click `Lab4aQ1.html` and select **Open with Live Server**.
4. Repeat with `Lab4aQ2.html` and `Lab4aQ3.html` to test each question.
